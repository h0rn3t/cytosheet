# Cytosheet Agent Documentation

## Про цей каталог

Каталог `.agent/` містить структуровану документацію для LLM агентів, які працюють над проектом cytosheet. Ця документація забезпечує швидкий контекст і чіткі інструкції для автоматизованої розробки.

## Структура документації

```
.agent/
├── README.md           # Цей файл - огляд структури
├── QUICKSTART.md       # Швидкий старт для агентів
└── specs/              # Технічні специфікації
    ├── requirements.md # Функціональні вимоги
    ├── design.md       # Архітектурний дизайн
    ├── tasks.md        # План розробки
    └── api-reference.md # API документація
```

## Призначення файлів

### QUICKSTART.md
Містить швидкий огляд проекту та інструкції для початку роботи агента. Читайте це першим.

### specs/requirements.md
Деталізовані функціональні вимоги до бібліотеки cytosheet, включаючи критерії сумісності з openpyxl.

### specs/design.md
Архітектурні рішення, структура модулів, підходи до оптимізації через Cython.

### specs/tasks.md
Поточні завдання розробки, пріоритети, чеклісти для імплементації.

### specs/api-reference.md
Повна довідка по API openpyxl, яку потрібно реалізувати в cytosheet.

## Як використовувати цю документацію

1. **Початок роботи**: Прочитайте `QUICKSTART.md`
2. **Розуміння вимог**: Ознайомтесь з `specs/requirements.md`
3. **Архітектура**: Вивчіть `specs/design.md`
4. **Розробка**: Використовуйте `specs/tasks.md` для планування
5. **Референс**: Звертайтесь до `specs/api-reference.md` під час імплементації

## Принципи роботи з документацією

- **Актуальність**: Оновлюйте документацію при змінах у коді
- **Конкретність**: Уникайте абстракцій, надавайте конкретні приклади
- **Тестовність**: Усі твердження мають бути перевіреними тестами
- **Сумісність**: Пріоритет - 100% сумісність API з openpyxl

## Версія проекту

- **Поточна версія**: 0.1.0
- **Цільова версія**: 1.0.0 (повна сумісність з openpyxl)
- **Python**: 3.7+
- **Залежності**: Cython ≥3.0.11, lxml ≥4.9

## Контакти і внесок

Цей проект розробляється з використанням LLM агентів для прискорення досягнення сумісності з openpyxl.
