# Cytosheet Agent Documentation

## Про цей каталог

Каталог `.agent/` містить структуровану документацію для LLM агентів, які працюють над проектом cytosheet. Ця документація забезпечує швидкий контекст і чіткі інструкції для автоматизованої розробки.

## Структура документації

```
.agent/
├── README.md                      # Цей файл - огляд структури
├── QUICKSTART.md                  # Швидкий старт для агентів
├── COMPATIBILITY_SUMMARY.md       # Краткая сводка совместимости API (NEW)
├── api_compatibility_analysis.md  # Детальный анализ совместимости (NEW)
└── specs/                         # Технічні специфікації
    ├── requirements.md            # Функціональні вимоги
    ├── design.md                  # Архітектурний дизайн
    ├── tasks.md                   # План розробки
    ├── examples.md                # Примеры использования
    ├── checklist.md               # Чеклисты реализации
    └── api-reference.md           # API документація
```

## Призначення файлів

### QUICKSTART.md
Містить швидкий огляд проекту та інструкції для початку роботи агента. Читайте це першим.

### COMPATIBILITY_SUMMARY.md ⭐ NEW
Краткая сводка совместимости API с openpyxl. Быстрый справочник с процентами, метриками и примерами.

### api_compatibility_analysis.md ⭐ NEW
Детальный анализ совместимости (6300+ строк). Полный breakdown по всем классам и методам openpyxl с оценкой реализации в cytosheet.

### specs/requirements.md
Деталізовані функціональні вимоги до бібліотеки cytosheet, включаючи критерії сумісності з openpyxl.

### specs/design.md
Архітектурні рішення, структура модулів, підходи до оптимізації через Cython.

### specs/tasks.md
Поточні завдання розробки, пріоритети, чеклісти для імплементації.

### specs/examples.md
Реальні примеры использования для типичных бизнес-сценариев (отчеты, шаблоны, ETL).

### specs/checklist.md
Чеклисты для проверки реализации функций перед релизом.

### specs/api-reference.md
Повна довідка по API openpyxl, яку потрібно реалізувати в cytosheet.

## Як використовувати цю документацію

### Для швидкого старту
1. **Початок роботи**: Прочитайте `QUICKSTART.md`
2. **Совместимость**: Откройте `COMPATIBILITY_SUMMARY.md` для быстрого обзора

### Для розробки
3. **Вимоги**: Ознайомтесь з `specs/requirements.md`
4. **Детальний аналіз**: Вивчіть `api_compatibility_analysis.md` для конкретного API
5. **Архітектура**: Прочитайте `specs/design.md`
6. **Задачі**: Используйте `specs/tasks.md` для планування

### Для імплементації
7. **Приклади**: Дивіться `specs/examples.md` для real-world сценаріїв
8. **Референс**: Звертайтесь до `specs/api-reference.md` під час розробки
9. **Перевірка**: Используйте `specs/checklist.md` перед коммітом

## Принципи роботи з документацією

- **Актуальність**: Оновлюйте документацію при змінах у коді
- **Конкретність**: Уникайте абстракцій, надавайте конкретні приклади
- **Тестовність**: Усі твердження мають бути перевіреними тестами
- **Сумісність**: Пріоритет - 100% сумісність API з openpyxl

## Версія проекту

- **Поточна версія**: 0.1.0
- **Цільова версія**: 1.0.0 (85%+ сумісність з openpyxl)
- **Python**: 3.7+
- **Залежності**: Cython ≥3.0.11, lxml ≥4.9

## Совместимость API

**Текущее состояние (v0.1.0)**:
- Базовый Core API: ~65% совместимость
- Практические сценарии (отчеты, шаблоны): ~90-95% совместимость
- Полный API openpyxl: ~45% совместимость

**Документация**:
- Полный анализ совместимости: `.agent/api_compatibility_analysis.md`
- Список задач и прогресс: `.agent/specs/tasks.md`

## Контакти і внесок

Цей проект розробляється з використанням LLM агентів для прискорення досягнення сумісності з openpyxl.
